## Features

- Live SERPER web search (real-time answers)
- Voice input/output
- Python code execution  
- Persistent chat memory (PostgreSQL)
- File browser
- Command palette (Ctrl+K)
- Expandable chat and preview windows
- 9 themes (Cyan default)

## Tech Stack

- Frontend: HTML/CSS/JS, Monaco Editor
- Backend: FastAPI (Python)
- Database: Neon PostgreSQL
- AI: Groq (Llama 3.3 70B / 8B)
- Search: SERPER API

## Deployment

All API keys are stored as environment variables, never in code.
